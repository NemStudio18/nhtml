Built for the Modern Web

NHTML eliminates frontend complexity by synchronizing the DOM through a high-performance binary pipeline.

⚡
Binary Speed

Uses Native Binary Packet Specification (NBPS) with Zstd compression for ultra-low bandwidth and sub-millisecond updates.

🐘
Server-Driven

No more state management on the client. Your PHP or Rust backend is the single source of truth for the entire DOM tree.

🛡️
Secure by Design

Mandatory HMAC-SHA256 signatures, sequence tracking, and strict Origin validation protect your app from XSS and hijacking.

🌐
Multi-Mode

Deploy as a Dedicated Rust Gateway, Shared PHP server, or Zero-Server static host via WebAssembly (PHP-WASM).

🔥
Hot Reload

Native file system watching with instant binary hydration. Edit your backend code and see the DOM patch in real-time.

🧩
Tiny Footprint

A 40KB JS bridge is all you need. No heavy framework bundles. No complex build steps for the frontend.
