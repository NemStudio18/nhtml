NHTML transforms your browser into a high-performance binary engine. Build complex reactive apps with zero business logic on the frontend.

📦 Native NBPS

A binary protocol optimized for atomic DOM mutations. Extremely low bandwidth using native Zstd compression.

🐘 Zero-JS Logic

Write your business logic in PHP or Rust. The Gateway orchestrates the state, the client strictly follows orders.

⚡ WASM Fallback

No server? No problem. NHTML boots a PHP virtual machine in the browser via WebAssembly for static hosting.

// Your Server Side Logic (app.php)
use Nhtml\Nhtml;

if ($event === 'click' && $nodeId === 'btn-buy') {
    Nhtml::patch()
         ->setText('status', 'Item Added!')
         ->addClass('cart', 'bump-animation')
