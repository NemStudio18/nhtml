# Nhtml Specification v2.0

Nhtml (Native HTML) is a reactive template language designed for high performance and portability.

## 1. Document Structure
Every Nhtml file should start with the version tag:
```html
<!nhtml 1.0>
```

## 2. Variables & State
States are declared using the `<var>` tag. They are reactive and scoped to the document.
```html
<var name="count" value="0">
<var site_name="My App">
```

## 3. Expressions
Expressions are wrapped in curly braces and evaluated against the internal state.
```html
<h1>Welcome to {site_name}</h1>
<p>Current count: {count + 1}</p>
```

## 4. Control structures
Nhtml uses specific tags for logic instead of attributes.

### Conditional
```html
<if condition="user.is_logged">
    <p>Hello {user.name}</p>
</if>
<else>
    <a href="/login">Login</a>
</else>
```

### Loops
```html
<each in="{posts}" as="p">
    <article>{p.title}</article>
</each>
```

## 5. Event Handling
Events are prefixed with `on:`. The value is a specialized OpCode list generated by the compiler.
```html
<button on:click="count++">Increment</button>
<button on:change="handle_change(this.value)">Update</button>
```

## 6. Architecture & Bridge
Nhtml follows a **Unidirectional Data Flow** with a **JS Bridge**:
1.  **Compiler**: Generates static HTML + a JSON Manifest (AST).
2.  **Runtime**: Small script (2KB) that hydrates the DOM using the Manifest.
