# Nhtml Installation Guide

Nhtml V2 can be deployed in three main ways depending on your needs:

*   **[PHP Integration](./docs/INSTALL-PHP.md)**: Best for existing PHP sites (CMS, Blogs).
*   **[Direct Server (CGI)](./docs/INSTALL-DIRECT.md)**: Fastest performance, zero-bridge deployment for Apache/Nginx.
*   **[Browser (WASM)](./docs/INSTALL-WASM.md)**: Zero-server dependency, ideal for PWAs and local development.

# 🇫🇷 Tutoriel d'Installation

Nhtml V2 peut être déployé de trois manières principales selon vos besoins :

*   **[Intégration PHP](./docs/INSTALL-PHP.md)** : Idéal pour les sites PHP existants (CMS, Blogs).
*   **[Direct Serveur (CGI)](./docs/INSTALL-DIRECT.md)** : Performance maximale, déploiement sans PHP pour Apache/Nginx.
*   **[Navigateur (WASM)](./docs/INSTALL-WASM.md)** : Zéro dépendance serveur, idéal pour les PWA et le développement local.
