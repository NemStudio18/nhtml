# ⚙️ Installation & Setup

[English](#-english) | [Français](#-français)

---

## 🇬🇧 English

NHTML can be installed by downloading the pre-compiled binary for your system or by building from source.

### 1. Download Binaries
Go to the [Releases](https://github.com/NemStudio18/nhtml/releases) page and download the version for your OS:
- **Windows**: `nhtml-windows.exe`
- **Linux**: `nhtml-linux`
- **macOS**: `nhtml-macos`

### 2. Quick Start
1. Place the binary in your project root.
2. Ensure you have PHP installed (if using the PHP SDK).
3. Run:
   ```bash
   ./nhtml start --dev
   ```
4. Open [http://localhost:8080](http://localhost:8080).

## 🇫🇷 Français

NHTML peut être installé en téléchargeant le binaire pré-compilé pour votre système ou en le compilant depuis les sources.

### 1. Télécharger les Binaires
Allez sur la page des [Releases](https://github.com/NemStudio18/nhtml/releases) et téléchargez la version correspondant à votre OS :
- **Windows** : `nhtml-windows.exe`
- **Linux** : `nhtml-linux`
- **macOS** : `nhtml-macos`

### 2. Démarrage Rapide
1. Placez le binaire à la racine de votre projet.
2. Assurez-vous d'avoir PHP installé (si vous utilisez le SDK PHP).
3. Lancez :
   ```bash
   ./nhtml start --dev
   ```
4. Ouvrez [http://localhost:8080](http://localhost:8080).
